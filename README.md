# 안녕하세요, 웹 구현과 디자인/영상 작업을 함께 하는 유종안입니다.

![포트폴리오 메인 화면](images/preview-desktop-home.png)

웹 화면을 구현하고, 필요한 기능을 붙이며, 디자인과 영상 콘텐츠까지 함께 다루는 작업을 합니다.
HTML/CSS/JavaScript 기반의 반응형 웹 구현을 중심으로 Next.js, TypeScript, Supabase, OpenAI API를 활용한 웹 도구까지 제작했습니다. Photoshop·Illustrator 디자인 작업과 Premiere Pro·After Effects 영상 편집, Blender 3D 작업도 함께 포트폴리오에 정리했습니다.

## About Me

- 웹 퍼블리싱과 프론트엔드 구현을 중심으로 작업합니다.
- HTML, CSS, JavaScript 기반의 반응형 웹사이트를 만들 수 있습니다.
- Next.js, TypeScript, Supabase, OpenAI API를 활용한 웹 서비스를 제작했습니다.
- Python Flask와 SQLite를 활용해 데이터 등록, 조회, 수정, 삭제가 가능한 관리자 페이지를 구현했습니다.
- LMS 개발 및 유지보수, 서버 관리, 업무용 웹/앱 개발 등 약 1년의 실무 경험이 있습니다.
- HeidiSQL을 활용해 데이터베이스 조회, 수정, 운영 데이터 관리 업무를 수행했습니다.
- Photoshop, Illustrator, Premiere Pro, After Effects, Blender를 활용해 디자인/영상/3D 결과물도 제작합니다.
- 사용자가 보기 편한 화면과 실제로 동작하는 결과물을 만드는 데 관심이 있습니다.

## Main Projects

### CareerLens AI 포트폴리오 분석
포트폴리오와 자기소개서 내용을 입력하면 지원 직무 기준으로 점수와 개선 방향을 정리해주는 웹 도구입니다. Next.js, TypeScript, OpenAI Structured Outputs, Supabase를 활용해 분석 요청, 결과 카드 렌더링, 저장, 히스토리, 공유 리포트, 삭제 기능을 구현했습니다.

- 배포: https://careerlens-ai-kohl.vercel.app/
- GitHub: https://github.com/ajttk369/CareerLens-AI
- 주요 기능: 입력 품질 점검, 종합/세부 점수, 개선 우선순위, 개선 문구 복사, 면접 질문/답변, PDF 저장, Supabase 저장/삭제

### Portfolio
개발, 디자인, 영상, 3D 작업을 한 페이지에서 확인할 수 있도록 제작한 개인 포트폴리오 사이트입니다. 반응형 레이아웃, 프로젝트 모달, 디자인 작업 라이트박스, 라이트/다크 모드를 구성했습니다.

### AI Future Expo
AI 전시 홍보를 위한 반응형 웹사이트입니다. HTML, CSS, JavaScript로 화면을 구현하고 Vercel에 배포했습니다. 페이지 안에 들어가는 영상 콘텐츠는 Premiere Pro와 After Effects를 활용해 제작했습니다.

### 학생 관리 시스템
Python Flask와 SQLite를 활용해 학생 데이터 등록, 조회, 수정, 삭제가 가능한 학생 관리 페이지를 제작했습니다. 검색/필터, 상태별 통계, SQLite 테이블 자동 생성 기능을 구현해 운영 데이터 관리 흐름을 보여주는 프로젝트입니다.

### Rift Record
Riot Games API를 활용해 League of Legends와 Teamfight Tactics 전적을 조회하고 분석하는 반응형 서비스입니다. LoL 최근 15경기와 TFT 최근 10경기, 게임 유형 필터, 상세 참여자 검색, 플레이스타일 분석, TFT 유닛·특성·증강체 한글화, Supabase 기반 자체 챔피언 티어를 구현해 Vercel에 배포했습니다.

- 배포: https://rift-record.vercel.app/
- GitHub: https://github.com/ajttk369/rift-record

### Shopping Mall Page
쇼핑몰 서비스를 가정해 제작한 웹 페이지입니다. 상품 목록, 브랜드, 이벤트, 검색, 마이페이지 등 쇼핑몰 흐름을 구성했고, Python을 활용한 백엔드 작업 경험도 함께 정리했습니다.

### Automatic Cup Collector
Raspberry Pi, Python, Machine Learning을 활용해 컵을 인식하고 분류하는 자동 인식 컵 수거기 프로젝트입니다. 시연 영상과 기획서 자료를 포트폴리오에서 확인할 수 있습니다.

### Smart Parking System
Arduino, NFC, Bluetooth를 활용한 스마트 무선 주차 시스템 프로젝트입니다. 주차 상태 확인 흐름을 구현했고, 교내대회에서 금상을 수상한 프로젝트입니다.
